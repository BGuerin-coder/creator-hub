# creator-hub

## Goal
Centralize all the content related to a creator using different social media for the communication, the shopping part, the subsciptions / gifts while avoiding fees from each platform.

## Features
- Presents the creator (home page)
    - Brief 
    - Photos
- Social Media
    - Youtube videos
    - Twitch reviews / clips
    - Instagram reels / posts
- Shopping
    - Checkout process 
    - Shopping cart
    - Product list
    - Product detail
    - Promotion
    - Pack of products
- Participation
    - Subscription
    - Gift
    - Crowdfunding 
    - Donnation goal
- Acknowledgements
    - Showing donator (from any source)
- Planning
    - Show expected dates for the next publications / lives
- Publication
    - Blog
    - Articles
    - BD
    - Poem
- Admin
    - Analytics
    - Content management
    - Permissions level
- Contact
- Recommendation (to support other creators)
